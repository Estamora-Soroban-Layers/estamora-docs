# Changelog

All notable changes to `estamora-docs` are recorded here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [0.1.0] - 2026-10-07

### Added
- Comprehensive documentation hub for Estamora protocol on Stellar (Soroban).
- 3-tier architecture guide (`concepts/the-layers.md`).
- Quickstart developer guide with `@estamora/sdk` (`getting-started/quickstart.md`).
- Core smart contract specifications and Soroban API reference (`reference/contracts.md`).
- TypeScript SDK guide and pre-flight simulation documentation (`reference/sdk.md`).
- Merchant & buyer web console manual (`reference/app.md`).
- Protocol security, timeout refund guarantees, and agent spend limits reference (`reference/security.md`).
- Live production deployment at [`https://estamora-docs.vercel.app`](https://estamora-docs.vercel.app).
